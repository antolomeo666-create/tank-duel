How online works

  1. The host runs node server.js and opens localhost:3000.
  2. Host clicks Host game and shares the 4-letter code.
  3. The friend opens the host's network address (shown in the server window), picks Online, types the code and clicks Join.
  4. When the friend has joined, the host presses START MATCH.
